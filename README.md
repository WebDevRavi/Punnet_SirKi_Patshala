# Puneet Sir Ki Pathshala

A clean, responsive one-page website for **Puneet Sir Ki Pathshala**, an online and offline learning initiative in Bhopal.

<img src="Capture.jpg" alt="Loading..."

## Highlights

- Responsive layout for mobile, tablet, and desktop
- Accessible structure with semantic HTML and a skip link
- No framework or build process required
- Current contact, registration, map, social, and YouTube links
- Privacy-friendly YouTube embeds (`youtube-nocookie.com`)

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

That’s it—there are no packages to install.

## Project structure

```
.
├── index.html       # Page content and links
├── main.css         # Responsive styling
├── promotion.jpg    # Original promotional artwork
└── README.md
```

## Customize before publishing

Please verify that the registration form, email address, social profiles, location, and YouTube videos are still current. These links were retained from the original site. The poster is treated as an archived promotion, since it mentions a past batch date.

## Deploy on GitHub Pages

1. Create a new GitHub repository and upload these files to its default branch.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and the `/ (root)` folder, then save.

GitHub will publish the website at `https://your-username.github.io/your-repository-name/`.
